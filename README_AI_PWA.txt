OFFLINE SMART LESSON PLAN GENERATOR

This version does NOT use OpenAI API, does NOT require an API key, and does NOT require paid services.

In Lesson Plan, enter/select:
- Class
- Subject
- Chapter Name

Then press “Generate Automatically”. The app creates editable lesson-plan content locally using built-in subject/topic teaching templates. You can edit, save and print the generated plan.

Because this is a local/offline generator, it is not connected to ChatGPT and does not provide open-ended generative AI. It is designed to work without an API or recurring API cost.
