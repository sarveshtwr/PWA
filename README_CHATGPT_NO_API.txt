CHATGPT NO-API LESSON PLAN MODE

This version does NOT call the OpenAI API and does NOT require OPENAI_API_KEY.

In Lesson Plan:
1. Enter/select Class.
2. Enter Subject.
3. Enter Chapter.
4. Press "Generate with ChatGPT".
5. ChatGPT opens with a prepared lesson-plan prompt. Review it and press Send.

The browser may also copy the prompt to the clipboard as a fallback. If the prompt is not prefilled in ChatGPT, paste the copied prompt into ChatGPT.

Important: A normal HTML/PWA page cannot silently use the user's ChatGPT account/session to receive a ChatGPT response and write it back into the page. That requires an official API/backend integration. This no-API version therefore opens ChatGPT for the user to send the prompt.
